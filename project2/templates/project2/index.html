Feature effect plots

Both curves are computed from scratch here, and both use the model selected above. Three curves each, one per species.

Partial dependence

Every penguin is copied with {{ feature_label }} set to each grid value, and the predicted probabilities are averaged. That average runs over combinations of features that may never occur, which is what makes a PDP easy to read and also what makes it mislead when features are correlated.

Accumulated local effects

ALE never invents a row: inside each bin only the penguins that really fall there are used. Computed by {{ ale_method }}. {% if exact %} Logistic regression is a softmax of a linear function, so ∂p/∂x is available in closed form. {% else %} A tree is piecewise constant, so its derivative is zero inside every leaf and undefined at the splits; a finite difference across each bin is the only thing that carries information. {% endif %} The strip along the bottom marks the bins that contain data.
